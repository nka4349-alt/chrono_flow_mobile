# 06 Test Scenarios

## 1. 初回起動
- アプリを起動する
- `/login` に入る、または既存ログイン済みならホームへ入る

## 2. ログイン
- メール / パスワードでログイン
- CSRF エラーが出ない
- ログイン後に `/` へ遷移する

## 3. ホーム
- カレンダーが描画される
- グループ drawer が開閉できる
- メンバー drawer が開閉できる

## 4. イベント
- 日付タップでイベント作成できる
- 保存ボタンが押せる
- イベント帯が表示される
- 月 / 週 / 日表示が切り替えられる

## 5. チャット
- グループ選択後にチャットスコープが変わる
- 入力欄タップで bottom sheet が開く
- 送信できる

## 6. 認証切れ
- セッション切れ時に `/login` へ戻れる
- 壊れた POST が残らない
