# 01 Product Context

## プロダクト名
ChronoFlow

## 一言でいうと
個人予定とグループ予定を、チャットと一緒に扱えるカレンダー中心のコラボアプリ。

## 現時点でコードから確認できること

### 認証
- `/login`
- `/signup`
- Cookie セッション認証

### メイン画面
- ルート `/` はホーム画面
- 中央にカレンダー
- 左にグループツリー
- 右にメンバー / フレンド周辺の情報
- 下部にチャット領域

### カレンダー
- month / week / day 表示
- イベント作成 / 更新 / 削除
- イベントに場所、説明、色がある
- 個人イベントとグループイベントを扱う

### ソーシャル機能
- グループ作成 / 編集 / 親子構造
- フレンド一覧
- フレンドリクエスト
- 1:1 チャット
- グループチャット
- イベントチャット

## モバイル v1 で狙う価値
- 予定確認をスマホで素早く行える
- グループ選択 → イベント確認 → チャット送信が 1 本でできる
- Web を作り直さずにベータ配布できる

## モバイルで特に重要な画面
1. ログイン
2. ホーム
3. 月カレンダー
4. グループ drawer
5. チャット bottom sheet
6. イベントモーダル

## v1 でやらないこと
- ネイティブ専用 UI への全面作り直し
- オフライン同期
- プッシュ通知の本格実装
- 課金導線の実装
