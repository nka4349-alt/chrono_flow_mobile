# Store Metadata Draft (JA)

## アプリ名
ChronoFlow

## 一言説明案
個人予定とグループ予定を、チャットと一緒に扱えるカレンダー。

## 長め説明案
ChronoFlow は、個人予定とグループ予定をひとつの流れで扱うためのカレンダーアプリです。
月・週・日カレンダーで予定を確認しながら、グループ単位の予定共有、イベント詳細の確認、チャットでのやりとりまでつなげられます。

## 主要ポイント案
- 個人とグループを切り替えて予定確認
- イベントに場所、説明、色を設定
- グループやイベント単位でチャット
- フレンドやグループメンバーとの連携
